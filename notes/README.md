# Running notes

Raw material for the yearly write-ups. Not published (this folder isn't read
by the site). One file per year, e.g. `2018.md`. Add a few lines whenever
something hard or good happens — dated, unpolished. At year end, turn them
into a post from `content/templates/year-in-review.md`.

Format per entry:

```
## 2018-08-14 — hard | win | wrong | lesson
What happened, what I did, what I'd do differently.
```

Keep employer-confidential details out of these too, so nothing sensitive
sits one copy-paste away from a public post.
